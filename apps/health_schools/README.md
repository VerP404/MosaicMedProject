# Школы здоровья (цель 307)

Справочник в БД + анализ талонов ОМС и плана ИСЗЛ.

```bash
python manage.py migrate health_schools
python manage.py import_health_schools "scripts/307 цель/Справочник 307 цели.xlsx"
```

Админка: **Диспансерное наблюдение → Школы здоровья (цель 307)**. Поле **Периодичность, лет** по умолчанию 3.

UI заведующего: `/head/health_schools`

- талоны цели 307 за год → школа, явки, код услуги;
- периодичность: повтор той же школы раньше срока;
- диагноз школы в плане ИСЗЛ на год;
- «К проведению»: план ИСЗЛ есть, курса 307 в периоде нет.
